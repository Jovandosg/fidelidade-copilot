# Como adicionar uma fonte

1. Copie este arquivo para um novo `.md` (nomes iniciados por `_` sao ignorados na ingestao).
2. Preencha `url` (https, dominio voeazul.com.br) e `consulted_at` (AAAA-MM-DD) com a pagina e o dia em que voce leu a regra.
3. Transcreva ou resuma apenas regras publicas, uma secao (`#`) por tema. Nunca inclua dados pessoais.
4. Rode `python -m src.knowledge`. Texto alterado cria nova versao; texto igual nao muda nada.
